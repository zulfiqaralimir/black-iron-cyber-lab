# 🛡 Security Log Analyzer  
A beginner-friendly cybersecurity tool that analyzes system logs, detects suspicious activity, and generates a clean visual report.

This project is developed as part of my (ISC)² Certified in Cybersecurity (CC) hands-on learning path.

---

## 🚀 Features

- 🔍 Parse SSH, Windows Event Logs, and Web Server Logs  
- 🚫 Detect failed login attempts  
- 🔥 Detect brute-force attack patterns  
- 🧱 Identify privilege escalation attempts  
- 📊 Generate visual security reports  
- 📁 Upload any `.log` or `.txt` file  
- 💡 Lightweight and beginner-friendly  

---

User → Streamlit UI → Python Backend → Detectors → Report
